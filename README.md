# Curso_Python_Estatistica_2
Curso de Estatística com Python - Probabilidade e Espaço Amostral

# 📊 Pesquisa Nacional por Amostra de Domicílios - 2015

## 📌 Sobre o Projeto
Este projeto tem como objetivo a análise estatística dos dados da **Pesquisa Nacional por Amostra de Domicílios (PNAD) de 2015**. A PNAD é uma pesquisa anual realizada pelo IBGE para investigar diversas características da população brasileira, incluindo educação, trabalho, rendimento, habitação, migração, saúde e outros fatores socioeconômicos.

O projeto utiliza **Python** e bibliotecas estatísticas para realizar a exploração, limpeza e análise dos dados, proporcionando insights valiosos sobre as condições de vida no Brasil em 2015.

---

## 📂 Estrutura do Projeto
📁 **data/** → Contém os arquivos de dados da PNAD 2015.  
📁 **notebooks/** → Jupyter Notebooks com análises estatísticas e visualizações.  
📁 **scripts/** → Códigos Python para limpeza, transformação e modelagem dos dados.  
📁 **reports/** → Relatórios gerados com insights da análise.  
📄 **README.md** → Documento com informações sobre o projeto.

## 🚀 Como Executar o Projeto
1. Clone este repositório:
   ```bash
   git clone https://github.com/JessicaSTMatos/Curso_Python_Estatistica_2.git
   ```
2. Acesse o diretório do projeto:
   ```bash
   cd pnad-2015
   ```
3. Crie e ative um ambiente virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate  # Windows
   ```
4. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
5. Execute os notebooks:
   ```bash
   jupyter notebook
   ```
